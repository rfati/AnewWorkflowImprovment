## Risks & open questions
1. **Environment.** This repository is the unconfigured template: doctor reports
   `scripts/check.conf missing`, so there is no check profile and no step prerequisite to meet
   (doctor 0 fail, 4 warn — the unconfigured-template warnings). ANEW's own check is
   `./scripts/doctor --strict` + `./scripts/selftest`, as CI runs it (`.github/workflows/check.yml`).
   On this Windows Git Bash machine one selftest run takes over 10 minutes. Recommendation: run
   selftest in the background locally while building; the full green of record is the CI run on
   the PR (ubuntu), cited with its SHA in Build evidence, as in plan 0004.
2. **Version label.** The spec says v1.25.0; README ("ships there as v1.25, v1.26") and every
   CHANGELOG heading use `v1.25`, and patch numbers belong to fixes. Recommendation: release as
   `v1.25` — the same release under the project's own label; approving this plan approves that
   reading (no spec revision).
3. **Two spaces or a tab between "sensitive" and "area"** (`Sensitive  area: x`) is not a
   declaration by Req. 1 ("a space or a hyphen") and stays fail-open. Recommendation: build
   Req. 1 as written (widening is a spec change, R-08); if review raises it, defer to the backlog.
4. **Existing `hasnt "<file>"` assertions get stricter.** They now also fail on the new warning
   (its line names the file), so they prove "no warning" for the readable spellings for free.
   Recommendation: keep them unchanged — that is AC-1's second half.
5. **CRLF files.** Line numbers are physical lines and a trailing `\r` is already tolerated by the
   value parse. Recommendation: no extra fixture — not a criterion, the parse is unchanged.
